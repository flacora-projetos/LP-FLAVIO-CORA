# Preços — Página de Qualificação para WhatsApp Ads

## Projeto único
- Preço: a partir de R$ 500 (BRL), variando conforme complexidade
- Inclui: página de qualificação personalizada, filtro estratégico de 6 perguntas, mensagem pré-preenchida para WhatsApp, integração com Meta Pixel + CAPI (eventos de otimização para Meta Ads)
- Não inclui: gestão de tráfego/anúncios, CRM, automação de atendimento, envio automático de mensagens

## Como contratar
Contato via WhatsApp pelo botão na [página principal](https://www.querominhapagina.com.br/). Orçamento é feito sob consulta, conforme escopo do projeto.
